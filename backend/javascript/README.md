# Backend mock JavaScript/TypeScript

Backend ligero para la PoC.

Su objetivo es exponer endpoints mock simples para alimentar el frontend sin introducir una plataforma pesada.

## Estructura inicial

- `src/routes`
- `src/modules`
- `src/shared`

## Endpoints iniciales

- `GET /health`
- `GET /api/apps`

## Makefile

- `make install`
- `make dev`
- `make build`
- `make start`
